# FreeRooms School - Server API

Backend server and Arbor MIS live scraper for FreeRooms School.

## Tech Stack
- Node.js & Express.js
- MongoDB Atlas & Mongoose
- Arbor MIS internal API integration

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up `.env` (copy `.env.example`):
   ```bash
   PORT=5000
   MONGODB_URI=your_mongodb_connection_string
   SCHOOL_URL=https://wrenn-school.uk.arbor.sc
   ```
3. Run server:
   ```bash
   npm run dev
   ```
