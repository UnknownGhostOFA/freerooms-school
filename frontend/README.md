# FreeRooms School - Frontend

Clean Arbor MIS-styled frontend for FreeRooms School, showing live 6th form study rooms and period-by-period matrices across Week A and Week B.

## Tech Stack
- Next.js 16 (App Router)
- React 19 & TypeScript
- Tailwind CSS
- Lucide Icons & Canvas Confetti

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000)
